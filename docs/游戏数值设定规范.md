## 一、总则

1. **代码为唯一数值来源**：所有数值以 `src/data/*.ts`、`src/stores/transcend.ts`、
   `src/stores/daily.ts`、`src/lib/offline-gains.ts` 中的定义为准。
2. **本文档记录三类内容**：数值梯度口径（带）、设计意图（为什么是这个数）、
   守恒约束（哪些数必须联动）。
3. **数值改动三连查**（改动任何数值前后必做）：
   - 引用完整性：`requires` / `unlocksStronghold` / `unlock target` / 套装 `memberIds` 零悬空
   - 计数守恒：成就阈值 = 内容总量（见 §十）；README 与《游戏设定与架构》计数同步
   - 回归断言：单元测试与回归脚本中的硬编码数值断言同步更新
4. **汇总类数值必须连乘实测**：文档中的「全拿满 +X%」类声明一律以代码效果连乘实测为准，
   不采信设计稿约数。

## 二、资源收入矩阵

5 种资源（能量/晶体/合金/数据/暗物质）的收入通道：

| 通道 | 能量 | 晶体 | 合金 | 数据 | 暗物质 |
|---|---|---|---|---|---|
| 建筑产线（4 层） | ✓ | ✓ | ✓ | ✓ | ✓ |
| 探索一次性奖励 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 据点胜利奖励 | ✓ | ✓(少数) | ✓ | ✓ | ✓ |
| 据点驻扎 idle | ✓ | ✗ | ✓ | ✓ | ✓ |
| 无尽远征奖励 | ✓ | ✓(v0.65 起) | ✓ | ✓ | ✓ |
| 每日签到/周期挑战 | ✓ | ✗ | ✗ | ✗ | ✓(挑战) |
| 离线收益（含随机事件） | ✓ | ✗ | ✓(事件) | ✓(事件) | ✗ |

- **晶体口径**：晶体是建筑成本重资源（全部 T3/T4 建筑吃晶体），历史上唯一无战斗/远征
  收入通道的资源。v0.65 起沉默者旗舰（silencer_3）胜利奖励含晶体 1e5，
  经远征奖励基准（=旗舰奖励 × 1.35^(d-1)）放大为远征晶体轴。
  驻扎 idle 仍不含晶体（有意：驻扎是能量/合金/数据/暗物质的补充通道）。
- **签到/挑战能量入 totals**：计入终身成就计数与本轮转生负熵，设计行为（v0.62 确定），
  量级 5e3–1e5，仅首转前后有感知。

## 三、建筑曲线

每扇区 4 层（T1–T4），20 建筑。核心梯度：

| 口径 | 数值带 | 说明 |
|---|---|---|
| 成本增长率 costGrowth | T1=1.18 / T2=1.15 / T3=1.13 / T4=1.10 | 层级越高增长越缓，鼓励向高层迁移 |
| L0 能量回本（基础层） | T1 20–2000s / T2 50–6667s / T3 143s–25000s / T4 167s–50000s | 跨资源建筑按能量成本÷主产出粗算 |
| 每级产出比（Tn→Tn+1） | ≥ ×2（实测 ×2.0–×8.75） | 能量线 8x/8.75x/8.6x 最平滑；其余扇区 2–4x |
| **跳层无倒挂**（硬约束） | 同扇区 L0 回本逐层单调不减 | 高层不得一上来就比低层更划算；倒挂 = 陷阱层（玩家应跳过该层） |

- **成本公式**：`ceil(baseCost × costGrowth^level)`（decimal.js，逐资源）。
- **合金线注记（v0.65 修正）**：离子铸造站（T3）每级产出曾为 0.35（仅比 T2 高 17%），
  能量回本 85714s、边际交叉 L≈146 实际不可达，构成「陷阱层」。已修正为 1.2
  （每级产出比 T2→T3 = ×4，能量回本 25000s，交叉 L≈75 与数据扇区同带）。
- **暗物质线口径**：探测器→实验室成本组合差异（实验室无晶体）为历史数据，无功能影响，
  维持现状；暗物质回本天然以「暗物质自偿 + 战略价值」衡量，不用能量口径。
- **无 maxLevel**：建筑等级无上限（数据无 maxLevel 字段），「全部满级」空态逻辑就位但
  数据上不触发。

## 四、科技树

43 项、8 分支、tier 1–5。核心口径：

- **效果类型**：production_mult / cost_mult / unlock / combat_mult / explore_mult /
  prestige_mult / offline_bonus / training_slot，经 EffectSystem 连乘聚合（getValue 类累加）。
- **各资源科技乘数合计（全研究）**：能量 ×1.56 / 晶体 ×1.82 / 合金 ×1.75 / 数据 ×1.95 /
  暗物质 ×2.1。能量最低是有意口径（能量是基础资源，靠建筑层级与转生树补足）。
- **cost_mult（科技成本）**：研究加速 ×0.85 + 量子核心遗物 ×0.9，可叠至 ×0.765。
- **combat_mult**：武器/护甲 ×1.2 + 舰队后勤 ×1.3 = 攻防各 ×1.56（科技面封顶）。
- **explore_mult**：×1.3 → ×1.5 → ×1.4 → ×1.5 连乘 = ×4.095（科技面封顶）。
- **training_slot**：基础 1 槽 + 集群操练 I/II 各 +1，封顶 3。
- **守恒约束**：科技总数变化时，成就 ach_tech_3 阈值、回归脚本 TECH_IDS 白名单、
  README/设定文档计数四处必须同步。

## 五、战斗数值

- **伤害公式**：`dmgDealt = min(目标总血, max(1, 攻×数量 − 防×数量×0.4))`；
  防御折算系数 0.4，保底伤害 1。
- **克制**：常规三角（突击→护卫→重装→突击）×1.5；灵能者对重装 ×2.0，被突击 ×1.5 反克。
  敌方单位以 `counteredBy` 挂玩家兵种克制键。
- **软墙（保留不动）**：保底 1 + 50 回合上限 = 「越级本该败」。低攻编队对高防据点
  每轮仅保底 1 点进展，50 回合磨不死即超时判负。
- **战斗种子化**：编队 id + 据点 id + 分钟级时间戳 → FNV-1a → mulberry32，
  同分钟同编队结果可复现，防 SL 刷随机。
- **兵种基础属性带**：攻 8–35 / 防 5–12 / 血 60–200；训练成本与时间随强度递增
  （5–30 秒/兵）；灵能者为唯一 rare（吃暗物质）。
- **据点强度梯度**（敌方总强度 = Σ(攻+防+血)×数量）：raider_1 ≈ 490 →
  silencer_3 ≈ 116,100，跨约 237 倍；模拟验证各期合理进度部队（同期科技/转生乘数）
  均可在 1–2 回合通过对应据点，无卡点。
- **tier 字段语义（v0.65 定义）**：据点 tier 是剧情章节标签（对应探索层叙事阶段），
  **不代表难度排序**；同 tier 内强度可差一个数量级（ruin_3 与 silencer_2 同 tier 4，
  强度差 15 倍）。难度梯度一律以敌方总强度为准。
- **驻扎 idle 定位**：idle ≤ 同期一条中级建筑产线（顶级 silencer_3 能量 5000/s ≈
  extractor L25 + dyson L15 的产能），是补充通道而非替代建筑线。

## 六、探索经济

10 节点（星核层 4 + 恒星系层 6），二叉汇合链。核心带：

- **能量奖励/成本比**：3–6x（首节点 3x 引导，其后稳定 5x 带，章节末节点 6x）。
- **时间曲线**：30s → 28800s（8h），跨层约 ×2–×6 递增；恒星系层节点 1.5h–8h，
  适配离线/自动化场景。
- **完成时间锁定**：startExplore 时按当时 exploreMult 锁定 endTime，
  此后乘数变化不影响进行中探索（防「加速回溯」套利）。
- **无并发上限**：多节点可同时探索；行动队列「进行中」口径上限 = 10 节点 + 3 训练槽。
- **守恒约束**：节点数变化时回归脚本 NODE_IDS 白名单与行动队列单测的硬编码节点清单同步。

## 七、无尽远征

- **敌方缩放**：`0.5 × 1.25^(d-1)`（D1 = 最强模板半强度温和开场）。
- **奖励缩放**：`1.35^(d-1)`，基准 = silencer_3 奖励。奖励增速 > 敌方增速（正斜率，
  越深越值得打）；遗物掉率 `min(0.95, 0.5+0.05d)`、稀有度偏向 `min(1, 0.5+0.05d)`。
- **模板轮换**：4 模板按 (d-1) mod 4 轮换（silencer_3/raider_5/beast_4/ruin_4）；
  **TEMPLATE_NORMALIZE 总强度归一化**到旗舰基准（系数实测：raider_5 ×5.33 /
  beast_4 ×4.13 / ruin_4 ×1.52），保证跨深度难度单调平滑。调模板数值必须保持归一化逻辑。
- **软墙灰区口径（v0.65 实测修正）**：刚全通部队（攻×3 防×2.5 量级）约 **D7–D10**
  进入胜负灰区；胜负对编队构成敏感，模板轮换允许 ±1 层抖动（非严格单调）。
  旧口径「D6–D8」为方案稿估算，以实测为准。
- **深度推进**：仅前沿（best+1）胜利推进 expeditionBest；重打已过深度只取奖励。
  expeditionBest 跨转生保留，hardReset 清零。防御性上限 999。

## 八、遗物

- **稀有度权重**：common 100 / rare 35 / epic 10 / legendary 2；
  bias 修正：`weight × (1 + bias × idx × 1.5)`（idx 为稀有度序号 0–3）。
- **池**：20 种（common 6 / rare 7 / epic 5 / legendary 2），允许重复掉落
  （instanceId 唯一，可叠装）。
- **效果量级带**：common +5% / rare +10–20% / epic +30–50%（或双效果）/
  legendary 多效果大幅（欧米伽三资源 +50% 与攻 +40%；沉默者之眼全产出 +30% 与负熵 ×2）。
- **合成（3 合 1）**：3 件同稀有度未装备遗物（legendary 顶档不可作材料）→
  高一档池随机产物；原子提交，任一校验失败零副作用。随机不定向是有意设计（保刷取动力）。
- **套装**：4 组按来源系别（掠夺者战团 4 件/巨兽血裔 3 件/先驱遗产 7 件/沉默者回响 6 件），
  20 件全覆盖；2 件 partial / 3 件满套 full 两档，加成刻意小额
  （+5%–+12%），套装是收集方向标而非第二权力轴。
- **槽位**：基础 4，转生树 +1 封顶 5。
- **守恒约束**：池数量变化时 ach_relic_4 阈值（=种类数）、套装 memberIds 覆盖率、
  回归脚本 20 种口径断言同步。

## 九、转生（奇点重启）

- **阈值**：本轮总能量 ≥ 3e5（首转预期 1.5–3h）。
- **负熵公式**：`floor(sqrt(总能量/3e5) × prestigeMult)`；首转保底 +1（
  首转至少 2 负熵可购两个 1 费节点）。
- **收入曲线锚点**（无 prestige 加成）：3e5→1 / 1e7→5 / 1e9→57 / 1e12→1825。
- **买断区**：14 节点共 68 负熵（1–10 费梯度），引导期目标；
  3 个自动化协议节点（建造 10/研究 10/探索 8）买后常开、只在线生效、
  每建筑每 tick 至多 1 级。
- **无限区**：4 节点（全产出 +10%/级、攻防 +5%/级、探索 +10%/级、离线 +10%/级），
  成本 `ceil(base × growth^level)`，growth 1.5（离线 1.6）。
  **自收敛机制**：负熵收入 sqrt 压缩 vs 成本指数增长 → 等级增速对数级放缓
  （t_inf_prod L10 累计 571 负熵 ≈ 单轮 9.8e10 能量，prestige 乘数拉低约两个数量级）。
- **不无限化名单（故意）**：prestige_mult（负熵生负熵正反馈失控）、
  relic_slot / starting_energy（无限叠加直接失衡）。
- **重置范围**：清 resources（含 totals）/buildings/research/military/
  combat.completed+garrisoned/exploration；保留 relics、负熵+树、转生次数、成就、
  expeditionBest。跨轮持久系统若统计依赖被清值，必须自设终身计数器。

## 十、成就

- **33 成就 9 类**；终身计数跨转生保留（hardReset 才清）；
  能量/暗物质走 totals 差值快照法（单点覆盖全产出通道）。
- **量级封顶（连乘实测）**：全拿满 = 全产出 +51.4% / 攻防 +46.9% / 探索 +39.2% /
  离线 +46.4% / 负熵 +10%。压在无限树单节点几级的量级内——顺路的糖，非第二权力轴。
  prestige_mult 仅 ach_relic_4 一个成就给 +10%。
- **远征深度成就（v0.69）**：ach_battle_4（D10，攻防 +5%）/ ach_battle_5（D20，攻防 +8%）
  读 expeditionBest 现值（跨转生保留，hardReset 才清零），不新增存档字段；
  成就面攻防连乘 1.05×1.08×1.12×1.02×1.05×1.08 ≈ ×1.469（+46.9%，
  v0.67 基线 +29.5%），科技面 ×1.56 合计约 ×2.29。D20 高于软墙灰区（D7-D10），
  是跨多轮转生的长线锚点。
- **阈值守恒**：ach_tech_3 阈值 = 科技总数（43）；ach_relic_4 阈值 = 遗物种类数（20，
  按 distinct id 计，不按持有件数）；desc 中的数字必须与 threshold 一致
  （大数用逗号分隔风格，不用科学计数法）。
- **老玩家口径**：历史产量不追溯，终身计数从装档起算；hydrate 后按当时现值补发
  遗物/转生/时长类。

## 十一、每日签到 / 周期挑战

- **签到**：tick 驱动自动（本地日期），连击 7 天循环；
  节点奖励 1/3/7 天 = 2e4+0 / 5e4+3 / 1e5+7（能量+暗物质），普通日保底 5e3 能量；
  断签回归包 5e4 能量 + 2 暗物质（叠加在当日奖励上）。
- **周期挑战**：每周一换新 3 项（5 模板池，FNV-1a + mulberry32 周种子确定性抽取，
  tier 档位错开）；奖励暗物质 3/5/8（转生类 8/12），领取勾连连击 +1。
- **量级原则**：与成就奖励同级「顺路的糖」，不造第二资源轴；
  暗物质周收入上限 ≈ 38（3 项挑战最高档 12+8+8 + 签到节点 3+7）。

## 十二、离线收益

- **效率 100% 无衰减**（V4.0 口径）；结算上限 24h；< 60s 不结算；
  ≥ 300s 才弹报告（后台标签页节流防误弹）。
- **offline_bonus 连乘封顶**：科技 ×1.2 + 转生树 ×1.5 + 无限节点 ×1.1^L +
  成就 ×1.464 + 遗物 ×1.1。
- **随机事件**：20% 概率，3 种（能量 60s / 数据 120s / 合金 30s 产量），
  基于建筑产能而非固定值。
- 离线期间训练队列照常补推进；自动化协议只在线生效（离线资源回线后由自动化花掉）。
