## 一、总则

1. **代码为唯一数值来源**：所有数值以 `src/data/*.ts`、`src/stores/transcend.ts`、
   `src/stores/daily.ts`、`src/lib/offline-gains.ts` 中的定义为准。
2. **本文档记录三类内容**：数值梯度口径（带）、设计意图（为什么是这个数）、
   守恒约束（哪些数必须联动）。
3. **数值改动三连查**（改动任何数值前后必做）：
   - 引用完整性：`requires`（据点解锁链以 `pve.requires` 为单一出处）/ `unlock target` / 套装 `memberIds` 零悬空
   - 计数守恒：成就阈值 = 内容总量（见 §十）；README 与《游戏设定与架构》计数同步
   - 回归校验：单元测试与回归脚本中的硬编码数值校验同步更新
4. **汇总类数值必须连乘实测**：文档中的「全拿满 +X%」类声明一律以代码效果连乘实测为准，
   不采信设计稿约数。

## 二、资源收入矩阵

5 种资源（能量/晶体/合金/数据/暗物质）的收入通道：

| 通道 | 能量 | 晶体 | 合金 | 数据 | 暗物质 |
|---|---|---|---|---|---|
| 建筑产线（4 层） | ✓ | ✓ | ✓ | ✓ | ✓ |
| 探索一次性奖励 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 据点胜利奖励 | ✓ | ✓(少数) | ✓ | ✓ | ✓ |
| 据点驻扎 idle | ✓ | ✗ | ✓ | ✓ | ✓ |
| 无尽远征奖励 | ✓ | ✓(v0.65 起) | ✓ | ✓ | ✓ |
| 每日签到/周期挑战 | ✓ | ✗ | ✗ | ✗ | ✓(挑战) |
| 离线收益（含随机事件） | ✓ | ✗ | ✓(事件) | ✓(事件) | ✗ |

- **晶体口径**：晶体是建筑成本重资源（全部 T3/T4 建筑吃晶体），历史上唯一无战斗/远征
  收入通道的资源。v0.65 起沉默者旗舰（silencer_3）胜利奖励含晶体 1e5，
  经远征奖励基准（=旗舰奖励 × 1.35^(d-1)）放大为远征晶体轴。
  驻扎 idle 仍不含晶体（有意：驻扎是能量/合金/数据/暗物质的补充通道）。
- **签到/挑战能量入 totals**：计入终身成就计数与本轮转生负熵，设计行为（v0.62 确定），
  量级 5e3–1e5（断签回归日叠加补偿后最高 1.5e5），仅首转前后有感知。

## 三、建筑曲线

每扇区 4 层（T1–T4），20 建筑。核心梯度：

| 口径 | 数值带 | 说明 |
|---|---|---|
| 成本增长率 costGrowth | T1=1.18 / T2=1.15 / T3=1.13 / T4=1.10 | 层级越高增长越缓，鼓励向高层迁移 |
| L0 能量回本（基础层） | T1 20–2000s / T2 50–6667s / T3 143s–25000s / T4 167s–50000s | 跨资源建筑按能量成本÷主产出粗算 |
| 每级产出比（Tn→Tn+1） | ≥ ×2（实测 ×2.0–×8.75） | 能量线 8x/8.75x/8.6x 最平滑；其余扇区 2–4x |
| **跳层无倒挂**（硬约束） | 同扇区 L0 回本逐层单调不减 | 高层不得一上来就比低层更划算；倒挂 = 陷阱层（玩家应跳过该层） |

- **成本公式**：`ceil(baseCost × costGrowth^level)`（decimal.js，逐资源）。
- **合金线注记（v0.65 修正）**：离子铸造站（T3）每级产出曾为 0.35（仅比 T2 高 17%），
  能量回本 85714s、边际交叉 L≈146 实际不可达，构成「陷阱层」。已修正为 1.2
  （每级产出比 T2→T3 = ×4，能量回本 25000s，交叉 L≈75 与数据扇区同带）。
- **暗物质线口径**：探测器→实验室成本组合差异（实验室无晶体）为历史数据，无功能影响，
  维持现状；暗物质回本天然以「暗物质自偿 + 战略价值」衡量，不用能量口径。
- **无 maxLevel**：建筑等级无上限（数据无 maxLevel 字段），「全部满级」空态逻辑就位但
  数据上不触发。

## 四、科技树

59 项、8 分支、tier 1–9。核心口径：

- **效果类型**：production_mult / cost_mult / unlock / combat_mult / explore_mult /
  prestige_mult / offline_bonus / training_slot，经 EffectSystem 连乘聚合（getValue 类累加）。
- **各资源科技乘数合计（全研究）**：能量 ×1.56 / 晶体 ×1.82 / 合金 ×1.75 / 数据 ×7.49112 /
  暗物质 ×5.99781。能量最低是有意口径（能量是基础资源，靠建筑层级与转生树补足）。
- **cost_mult（科技成本）**：研究加速 ×0.85 + 量子核心遗物 ×0.9，可叠至 ×0.765。
- **combat_mult**：武器/护甲 ×1.2 + 舰队后勤 ×1.3 + 旗舰协同 ×1.25 + 联合舰队战术 ×1.25 +
  星河统帅 ×1.25 + 虚空统帅 ×1.25 = 攻防各 ×3.80859375（科技面封顶）。
- **explore_mult**：×1.3 → ×1.5 → ×1.4 → ×1.5 → ×1.3 → ×1.3 → ×1.3 → ×1.3 连乘 =
  ×11.6957295（科技面封顶）。
- **training_slot**：基础 1 槽 + 集群操练 I/II 各 +1，封顶 3。
- **守恒约束**：科技总数变化时，成就 ach_tech_3 阈值、回归脚本 TECH_IDS 白名单、
  README/设定文档计数四处必须同步。

## 五、战斗数值

- **伤害公式**：`dmgDealt = min(目标总血, max(1, 攻×数量 − 防×数量×0.4))`；
  防御折算系数 0.4，保底伤害 1。目标总血按「(存活数−1)×单兵上限血 + 残兵血」
  还原（v0.93 修正：受击后残兵血×存活数的旧口径会把多单位组血池腰斩，
  使低攻编队能在回合上限内磨死高血堆叠，超时软墙失效）。
- **克制**：常规三角（突击→护卫→重装→突击）×1.5；灵能者对重装 ×2.0，被突击 ×1.5 反克。
  敌方单位以 `counteredBy` 挂玩家兵种克制键。
- **软墙（保留不动）**：保底 1 + 50 回合上限 = 「越级本该败」。低攻编队对高防据点
  每轮仅保底 1 点进展，50 回合磨不死即超时判负。
- **战斗种子化**：编队 id + 据点 id + 分钟级时间戳 → FNV-1a → mulberry32，
  同分钟同编队结果可复现，防 SL 刷随机。
- **兵种基础属性带**：攻 8–35 / 防 5–12 / 血 60–200；训练成本与时间随强度递增
  （5–30 秒/兵）；灵能者为唯一 rare（吃暗物质）。
- **据点强度梯度**（敌方总强度 = Σ(攻+防+血)×数量）：raider_1 ≈ 245 →
  silencer_4 ≈ 592,300（v0.71 星团层旗舰）→ silencer_5 ≈ 4,052,200（v0.90 星臂层旗舰）→
  silencer_6 ≈ 11,526,600（v0.91 星系层旗舰）→ silencer_7 ≈ 32,965,680（v0.92 深空层
  终章），跨约 13.5 万倍；模拟验证各期合理进度部队（同期科技/转生乘数）均可在 1–2
  回合通过对应据点，无卡点（星团层三档模拟：门槛档 gate 1–2 回合、深层 3 回合属预期
  梯度；星臂层三档模拟：门槛档 gate 1–2 回合、终章 3–4 回合为进度墙；星系层三档模拟：
  门槛档 gate 2 回合、终章 4 回合为进度墙；深空层三档拟：门槛档 gate 2 回合、终章
  3–4 回合为进度墙；四层中位/满配档全据点 1–2 回合，忠实移植 resolveBattle 验证）。
- **据点奖励同系递进（v0.83 校勘）**：同系 tier 6 奖励逐项 ≥ tier 5 现值
  （v0.71 承诺口径）；v0.90 起 tier 7、v0.91 起 tier 8、v0.92 起 tier 9 同口径校准
  （逐项 ≥ 同系上档现值）。
  raider_6 原缺 alloy，补 80000（= raider_5 的 50000 ×
  能量奖励比 1.6，与能量档位同步进阶）。
- **tier 字段语义（v0.65 定义）**：据点 tier 是剧情章节标签（对应探索层叙事阶段），
  **不代表难度排序**；同 tier 内强度可差一个数量级（ruin_3 与 silencer_2 同 tier 4，
  强度差 15 倍）。难度梯度一律以敌方总强度为准。
- **驻扎 idle 定位**：idle ≤ 同期一条中级建筑产线（顶级 silencer_7 能量 150000/s、
  silencer_6 60000/s、silencer_5 30000/s ≈ extractor L25 + dyson L15 的产能量级），
  是补充通道而非替代建筑线。
- **编队特性（v1.23）**：三支编队各自可从五项特性中选一项，免费即时切换，
  默认均衡无加成。生效面为编队口径：强攻学说攻击 ×1.12 / 坚壁学说血量 ×1.15 /
  破敌学说克制伤害倍率 +0.25（1.5→1.75、灵能 2.0→2.25，仅克制命中时兑现）/
  后勤学说所驻据点挂机产出 ×1.2（在线、离线与预览三路经 garrisonIdleReward
  单点生效）。乘区叠放位置：攻击乘区在全局攻乘数之后、血量乘区在单兵
  maxHp 上、克制增量在兵种 counterMult 上加算；全军面板与库存不乘特性。
  存档 trait 为编队可选字段（缺省 = 均衡，未知 id 读取侧回落不拒档）。
  校准实测（三档战斗模拟，200 局定稿）：终层五据点胜率零下降；远征前沿
  全胜截止 D32/D36（档C 为模板锯齿带：均衡 D37、坚壁 D40），边缘带增量
  集中于个别模板步（报告项），全灭区零翻盘（定性跳变零命中）；坚壁血量
  +15% 不破 50 回合软墙语义。

## 六、探索经济

34 节点（星核层 4 + 恒星系层 6 + 星团层 6 + 星臂层 6 + 星系层 6 + 深空层 6），二叉汇合链。核心带：

- **能量奖励/成本比**：3–6x（首节点 3x 引导，其后稳定 5x 带，章节末节点 6x）；
  星团层全链能量奖励合计 ≈3.31e10（恒星系层 3.89e8 的约 85 倍，放缓的膨胀节奏），
  星臂层全链 ≈8.75e11（星团层的 26.4 倍，同口径递减），
  星系层全链 ≈2.19e13（星臂层的 25 倍，同口径递减），
  深空层全链 ≈5.26e14（星系层的 24 倍，同口径递减），终章一次性、不构成第二收入轴。
- **时间曲线**：30s → 691200s（192h），跨层约 ×2–×6 递增；恒星系层节点 1.5h–8h，
  星团层节点 12h–24h，星臂层节点 24h–48h（两天一收），星系层节点 48h–96h（四天一收），
  深空层节点 96h–192h（八天一收），适配离线/自动化场景。
- **完成时间锁定**：startExplore 时按当时 exploreMult 锁定 endTime，
  此后乘数变化不影响进行中探索（防「加速回溯」套利）。
- **无并发上限**：多节点可同时探索；行动队列「进行中」口径上限 = 34 节点 + 3 训练槽。
- **守恒约束**：节点数变化时回归脚本 NODE_IDS 白名单与行动队列单测的硬编码节点清单同步。

## 七、无尽远征

- **敌方缩放**：`0.5 × 1.25^(d-1)`（D1 = 最强模板半强度温和开场）。
- **奖励缩放**：`1.35^(d-1)`，基准 = silencer_3 奖励。奖励增速 > 敌方增速（正斜率，
  越深越值得打）；遗物掉率 `min(0.95, 0.5+0.05d)`、稀有度偏向 `min(1, 0.5+0.05d)`。
- **模板轮换**：4 模板按 (d-1) mod 4 轮换（silencer_3/raider_5/beast_4/ruin_4）；
  **TEMPLATE_NORMALIZE 总强度归一化**到旗舰基准（系数实测：raider_5 ×5.33 /
  beast_4 ×4.13 / ruin_4 ×1.52），保证跨深度难度单调平滑。调模板数值必须保持归一化逻辑。
- **软墙灰区口径（v0.65 实测修正）**：刚全通部队（攻×3 防×2.5 量级）约 **D7–D10**
  进入胜负灰区；胜负对编队构成敏感，模板轮换允许 ±1 层抖动（非严格单调）。
  旧口径「D6–D8」为方案稿估算，以实测为准。
- **深度推进**：仅前沿（best+1）胜利推进 expeditionBest；重打已过深度只取奖励。
  expeditionBest 跨转生保留，hardReset 清零。防御性上限 999。
- **里程碑奖励（v1.20）**：档位 = floor(best / 10)，第 10 层起每 10 层一档；
  档位奖励 = 深度 10×tier 合成据点的资源奖励（与战斗奖励同源缩放），约为前一
  整档段累计战斗收入的 27%（≈ 1/3.67），随深度自缩放、不封顶。
  领取记录与深度同为终身数据；v1.19 旧档缺失视为空，未领档位
  可补领。
  校准实测（v092 引擎三档）：刚通关约推至 D15、中段 D25、满配 D35 附近、
  D40 进入软墙，档位节奏与进度带对齐。
- **每周强敌（v1.24）**：每周一（ISO 周，与周期挑战同轨）刷新一只强化据点
  Boss，入口在星图无尽远征区块，可见门槛与远征一致（本轮攻克沉默者旗舰
  解锁）。编成 = 远征 4 模板之一（周种子洗牌取 1）× TEMPLATE_NORMALIZE
  归一 × endlessScale(深度)，模板与 endless 轮换表同源但独立冻结。
  深度公式：bossDepth = max(6, expeditionBest + OFFSET)，OFFSET = silencer_3
  −1 / raider_5 +1 / beast_4 −2 / ruin_4 +2（按三档 50% 墙位 D33/D37/D40
  的模板结构分量定标），锚终身远征前沿实时派生不冻结。
  奖励锚前沿、与模板解耦：endlessStronghold(max(6, best+1)) 全套 ×1.5
  （dark/energy/alloy/data/crystal 同比），量级 = 1.5 场前沿远征单场，
  周频一次性不构成第二资源轴；战损真实结算，失败无惩罚可重试。
  校准实测（六轮，200 局/格）：推进中玩家（墙−4 及以前）全模板全胜为周
  津贴；卡墙玩家各格胜率 19%–82% 落 [15, 85]% 可过带；已知残留 = 卡墙期
  周间体感差（档C 极差约 46pp，均在可过带），上线后可调 OFFSET 不动公式
  形态。击败即时发放并标记本周已击败，标记随转生清零（转生当周可再打）；
  Boss 不入敌方图鉴、严禁进 completedStrongholds（校验白名单会拒档）。

## 八、遗物

- **稀有度权重**：common 100 / rare 35 / epic 10 / legendary 2；
  bias 修正：`weight × (1 + bias × idx × 1.5)`（idx 为稀有度序号 0–3）。
- **池**：20 种（common 6 / rare 7 / epic 5 / legendary 2），允许重复掉落
  （instanceId 唯一，可叠装）。
- **效果量级带**：common +5% / rare +10–20% / epic +30–50%（或双效果）/
  legendary 多效果大幅（欧米伽三资源 +50% 与攻 +40%；沉默者之眼全产出 +30% 与负熵 ×2）。
- **合成（3 合 1）**：3 件同稀有度未装备遗物（legendary 顶档不可作材料）→
  高一档池随机产物；原子提交，任一校验失败零副作用。随机不定向是有意设计（保刷取动力）。
- **套装**：4 组按来源系别（掠夺者战团 4 件/巨兽血裔 3 件/先驱遗产 7 件/沉默者回响 6 件），
  20 件全覆盖；2 件 partial / 3 件满套 full 两档，加成刻意小额
  （+5%–+12%），套装是收集方向标而非第二权力轴。
- **槽位**：基础 4，转生树 +1 封顶 5。
- **守恒约束**：池数量变化时 ach_relic_4 阈值（=种类数）、套装 memberIds 覆盖率、

- **强化等级轴（v0.70）**：每件遗物实例独立等级 0–20 级（统一封顶）；消耗纯能量；

## 九、转生（奇点重启）

- **阈值**：本轮总能量 ≥ 3e5（首转预期 1.5–3h）。
- **负熵公式**：`floor(sqrt(总能量/3e5) × prestigeMult)`；首转保底 +1（
  首转至少 2 负熵可购两个 1 费节点）。
- **收入曲线锚点**（无 prestige 加成）：3e5→1 / 1e7→5 / 1e9→57 / 1e12→1825。
- **买断区**：14 节点共 68 负熵（1–10 费梯度），引导期目标；
  3 个自动化协议节点（建造 10/研究 10/探索 8）买后常开、只在线生效、
  每建筑每 tick 至多 1 级。
- **无限区**：4 节点（全产出 +10%/级、攻防 +5%/级、探索 +10%/级、离线 +10%/级），
  成本 `ceil(base × growth^level)`，growth 1.5（离线 1.6）。
  **自平衡机制**：负熵收入 sqrt 压缩 vs 成本指数增长 → 等级增速对数级放缓
  （t_inf_prod L10 累计 571 负熵 ≈ 单轮 9.8e10 能量，prestige 乘数拉低约两个数量级）。
- **不无限化名单（故意）**：prestige_mult（负熵生负熵正反馈失控）、
  relic_slot / starting_energy（无限叠加直接失衡）。
- **重置范围**：清 resources（含 totals；暗物质余额保留，跨转生不清零（resources.reset(true) 的 keepDark 分支显式保留 amounts.dark））/buildings/research/military/
  combat.completed+garrisoned/exploration；保留 relics、负熵+树、转生次数、成就、
  expeditionBest。跨轮持久系统若统计依赖被清值，必须自设终身计数器。

## 十三、数值显示格式（fmt）

玩家可见数值统一走 `src/lib/format.ts` 管线，口径如下（v0.86.2 代码实测；v0.95 修订舍入与超档小节）。

### fmt 通用数值

- **后缀档位**：22 档千进位后缀，空档（<1e3）、K、M、B、T、Qa、Qi、Sx、Sp、
  Oc、No、Dc、UDc、DDc、TDc、QaDc、QiDc、SxDc、SpDc、OcDc、NoDc、Vg；
  达到 1e63 超档后回退科学计数法并去尾零（`1e66` / `1.5e66` 形态，v0.95）
- **裸显区间**：绝对值 < 1000 不带后缀。< 10 保留两位小数（去尾零）、
  < 100 保留一位小数（去 `.0`）、≥ 100 直接取整；小数统一朝零截断（v0.95）
- **进位规则**：scaled 值达到 999.95 必须升档（例：999,999.5 显示为 1M
  而非 999.9K）；进位后显示值恒为 1（v0.78 修正）
- **负值**：与正值同规则并朝零截断，不越单位边界（如 -999.5 显示 `-999`），
  前缀负号；归零的极小负值显示「0」（v0.95）
- **兜底**：NaN / 非有限值显示「0」

### 专项格式化

| 函数 | 口径 |
|---|---|
| fmt | 主格式化管线：单位后缀 + 进位 + 截断，全部玩家可见数值的唯一入口 |
| fmtTime | 秒转友好时长：`53s` / `5m 3s` / `2h 5m` / `1d 2h`；负值与非有限值兜底 0s |
| fmtRate | 每秒产量：`+1.2K /s`；零产出显 `0 /s`；负值无前导正号 |

### 使用约束

- 玩家可见的成本、产出、奖励、余额一律走 fmt 管线，禁止裸数字拼接
- fmt 对 number 与 Decimal 入参统一按 Decimal 口径截断（v0.95），展示不受入参类型影响
- 转生树节点成本自 v0.86.1 起接入 fmt（此前为全站唯一违例）
- 数值变动刷新以 fmt 后字符串比对为准（TopBar 资源闪动触发条件）
