## v1.10 — 工程化: 分享图转 WebP 与冗余字体分片删除

**变更性质：工程化（线上资产瘦身，视觉与功能零变化）**
**开发时间：2026-09-18**

### 概述

线上资产瘦身：分享图 og.png 转码为 WebP，336 KB 降至约 27 KB，
线上省约 309 KB；删除零字符命中的 JetBrains Mono 西文扩展字体
分片，省 11.6 KB 与一个请求。仓库与预览保持相对路径形态，部署
侧分享元数据注入逻辑同步改指新文件名。

### 变更明细

- 分享图转码：public/og.png 转码为 public/og.webp，尺寸 1200×630
  不变，质量 85 编码；index.html 的 og:image 与 twitter:image 指向
  同步更新；deploy.sh 分享元数据注入的文件名与命中计数同步改指
  og.webp；README 双语头图引用同步更新。
- 字体分片删除：public/fonts/JetBrainsMono-latin-ext.woff2 在全库
  源码、文案与文档中零字符命中，连同 fonts.css 对应 @font-face
  块一并删除；字形由 latin 分片与后备字体承接，页面字体无变化。
- 验证脚本：回归套件内分享卡检查改指 og.webp 与 image/webp；新增
  资产探针脚本，覆盖分享图可达性与尺寸、旧文件下线、字体分片
  下线与保留分片可达、字体可加载。

- Playwright 回归套件 27 脚本全过；非套件专项 9 份全过，含新增
  资产探针 8 断言。

## v1.07 — 重构: UI 层组件与样板收敛

**变更性质：重构（UI 层同构实现的组件化与工具化收敛，行为与视觉不变）**
**开发时间：2026-09-18**

### 概述

UI 层多处以复制粘贴方式维护的同构实现收敛为共享组件与组合式函数：图
标引用统一为 Icon 组件、确认弹窗收敛为 ConfirmModal 骨架、战斗日志行
抽为 LogList；六处定时器句柄样板、导航高亮、外点关闭、批量按钮文案与
资源行组装各收敛到单一出处。另新增最小圆角 Token --radius-xs 登记 3px
场景，并清理只做转手的 computed 与重复别名。全部改动保持 DOM 类名、
文案与交互行为不变，测试基线不变。

### 变更明细

- 新增 Icon.vue：全站 svg 与 use 图标引用统一为 Icon 组件形态，根节
  点仍为 svg、子节点保留 use 结构，类名与其余属性透传；19 个文件共
  34 处调用点替换，原始内联写法零残留。
- 新增 ConfirmModal.vue：部队批量、转生三弹窗与挂机驻扎共五处确认弹
  窗收敛为共用骨架，标题与说明经插槽承载以保留各视图 scoped 样式链，
  按钮文案、读屏标签与色调逐处保留。
- 新增 LogList.vue：页面日志区与结果弹窗战报共用同一行体，容器类名
  与日志行样式随子组件迁移。
- 新增 useTimeout 及按 key 的多路变体：六处 setTimeout 句柄样板收敛，
  重触发清旧与卸载清理统一承载，跃迁白光此前缺失的卸载清理一并补齐。
- 新增 useActiveNavId、useClickOutside、useBulkLabel 与资源行组装助
  手：侧栏与底栏导航高亮、底栏外点关闭、建造与转生与强化三处批量按
  钮文案、离线报告与战报与星图与顶栏的资源行各收敛到单一出处；日期
  格式化助手上收一档，成就解锁时间与每日模块共用。
- UpgradeCountdown.vue：四种倒计时行形态收敛为数据驱动的单一行体，
  混合态两行间距改由相邻边距表达。
- 星图探索进度改读主循环每秒时间戳驱动刷新并删除自建定时器；节点卡、
  部队卡与建筑卡改为一次性派生视图行，模板不再重复调用 getter；快速
  操作入口改由导航数据表派生且文案保持原样。
- 清理 21 处只做转手的 computed 与 4 处提示别名，调用点直读 store。
- 新增 --radius-xs 并入圆角族，替换小徽标、滚动条与星图进度条共 8 处
  硬编码 3px；《设计Token规范》总表同步登记。
