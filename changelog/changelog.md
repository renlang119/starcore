## v1.71 — 功能: 周强敌显示名接入帝庭威胁名录

**变更性质：功能（周强敌名换装剧情条目，机制与数值零变化）**

**开发时间：2026-10-18**

### 概述

每周强敌此前以通用「每周强敌·第 X 层」示人，跨周形貌无差别。
本版以帝庭档案视角为周强敌立「威胁名录」：四模板族（王庭失格
者 / 兽灾 / 先驱遗产 / 不可交涉系）各设 8 个条目，共 32 条按周
轮换，战斗页据点名显示「每周强敌·条目名」、描述位显示一行出
身注。条目轮换沿用既有周种子（同周同条目），深度、奖励、模板
轮换与克制考题零变化；条目未命中回退通用键，存档格式不变，
兼容既有存档。

### 变更明细

- 内容：weekly-boss 扩剧情条目池（四族 × 8 条）与条目轮换
  （沿 fnv1a 周种子洗牌取 1，同周同条目、跨周重洗）；合成据点
  显示名与描述读条目（名 = 「每周强敌·条目名」，与敌方名前缀
  同口径；描述 = 出身注），池未命中回退通用键
- 语言包：双语各新增 64 键（1371 至 1435），条目名与出身注
  中英对照，称谓与用词按术语表分野落笔
- 测试：新增 5 用例（四族池结构 8 条非空且族内条目名不重
  复 / 同周条目确定性 / 连续 24 周至少 4 个不同条目 / 装配
  接线连投四周验证换装与前后缀口径 / 兜底路径空池与未知模
  板返回 undefined 且通用回退键可解析）
- 文档：设定架构册与数值规范册同步显示名口径（数值零变化
  注记）
- 版本：package.json 1.70.0 → 1.71.0

### 验证

- check 全链全绿：构建、58 个测试文件 802 个用例（新增 5）、
  覆盖率阈值三档、计数守恒、文案守卫 strict（1435 键，术语分野
  零命中）、体积预算（226.9 / 256 KiB）、lint、格式检查与文档
  一致性检查（零告警）
- 既有 weekly-boss 全部 12 用例原样全绿（机制零回归证明）
- 端到端：周强敌三件专项（weekly-boss / boss-probe /
  walkthrough）与冒烟、英文语言探针全绿，战斗页据点名含
  「每周强敌·」前缀断言通过
- 负向注入：键名改一位 → 缺键 / 未使用键 / 键面一致性三段挂
  红；出身注注入「王庭帝庭」拼接 → 术语分野禁用挂红；还原后
  均恢复通过
