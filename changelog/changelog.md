## v1.07 — 重构: UI 层组件与样板收敛

**变更性质：重构（UI 层同构实现的组件化与工具化收敛，行为与视觉不变）**
**开发时间：2026-09-18**

### 概述

UI 层多处以复制粘贴方式维护的同构实现收敛为共享组件与组合式函数：图
标引用统一为 Icon 组件、确认弹窗收敛为 ConfirmModal 骨架、战斗日志行
抽为 LogList；六处定时器句柄样板、导航高亮、外点关闭、批量按钮文案与
资源行组装各收敛到单一出处。另新增最小圆角 Token --radius-xs 登记 3px
场景，并清理只做转手的 computed 与重复别名。全部改动保持 DOM 类名、
文案与交互行为不变，测试基线不变。

### 变更明细

- 新增 Icon.vue：全站 svg 与 use 图标引用统一为 Icon 组件形态，根节
  点仍为 svg、子节点保留 use 结构，类名与其余属性透传；19 个文件共
  34 处调用点替换，原始内联写法零残留。
- 新增 ConfirmModal.vue：部队批量、转生三弹窗与挂机驻扎共五处确认弹
  窗收敛为共用骨架，标题与说明经插槽承载以保留各视图 scoped 样式链，
  按钮文案、读屏标签与色调逐处保留。
- 新增 LogList.vue：页面日志区与结果弹窗战报共用同一行体，容器类名
  与日志行样式随子组件迁移。
- 新增 useTimeout 及按 key 的多路变体：六处 setTimeout 句柄样板收敛，
  重触发清旧与卸载清理统一承载，跃迁白光此前缺失的卸载清理一并补齐。
- 新增 useActiveNavId、useClickOutside、useBulkLabel 与资源行组装助
  手：侧栏与底栏导航高亮、底栏外点关闭、建造与转生与强化三处批量按
  钮文案、离线报告与战报与星图与顶栏的资源行各收敛到单一出处；日期
  格式化助手上收一档，成就解锁时间与每日模块共用。
- UpgradeCountdown.vue：四种倒计时行形态收敛为数据驱动的单一行体，
  混合态两行间距改由相邻边距表达。
- 星图探索进度改读主循环每秒时间戳驱动刷新并删除自建定时器；节点卡、
  部队卡与建筑卡改为一次性派生视图行，模板不再重复调用 getter；快速
  操作入口改由导航数据表派生且文案保持原样。
- 清理 21 处只做转手的 computed 与 4 处提示别名，调用点直读 store。
- 新增 --radius-xs 并入圆角族，替换小徽标、滚动条与星图进度条共 8 处
  硬编码 3px；《设计Token规范》总表同步登记。
- 规模：src 37 个文件 +841/-876，净减 35 行；用例数不变。

### 验证

- corepack pnpm check 全绿：33 个测试文件 476 个用例。
- 含 Playwright 段的计数守恒全绿。
- Playwright 回归套件 27 脚本全过；非套件专项 5 份全过。
- 部署后线上复跑 17 脚本全过。
- 线上 bundle 哈希与本地构建逐字节一致。

## v1.06 — 修复: 玩家名校验补强与版本历史启用第四档

**变更性质：修复（存档校验补强与文档同步，正常存档不受影响）**
**开发时间：2026-09-18**

### 概述

存档校验补上玩家名字段的类型与长度约束：该字段在存档管理区展示，
此前只校验到对象层，数字、对象或超长字符串仍可入档并展示。同步回
写《存档与数据安全规范》与《体验增强设计规范》两处口径，安全专项
的玩家名 XSS 载荷亦换为长度上限内的可触发形态。版本历史三档容量
已满，启用第四档承载 v1.06 起条目。

### 变更明细

- 存档校验：`src/lib/storage.ts` 的玩家名字段改为字符串且长度不超
  过 24 字符，超限整档拒绝；补 `_isBool` 判定助手并收敛两处布尔
  判定，另有一处非负判定展开写法收敛为既有助手。存档结构与写入
  语义不变。
- 存档规范回写：《存档与数据安全规范》§九 登记存档管理区元信息
  行（指挥官名与「本地存档」标识），§四 结构校验拒绝项补玩家名
  条目，册头同步行更新至 v1.06。
- 体验规范回写：《体验增强设计规范》§3.3.5 的 `dismiss()` 伪码
  改为与实现一致的单次读取形态，册头同步行更新至 v1.06。
- 测试：补玩家名约束用例（非字符串与超长拒绝、上限内接受），测
  试基线 33 个文件 476 个用例；README 双语基线同步。
- 安全专项：v087 脚本补上加载档注入接线（此前注入未实际生效），
  玩家名 XSS 载荷换为 24 字符内的可触发形态，另加载荷活性自检，
  转义路径转为真实跑测。
- 术语：组件注释一处计数表达改中性说法。
- 版本历史：三档容量填满，原活跃档转为历史存档
  `changelog-v0.71-v1.05.md`，新活跃档承载 v1.06 起条目；四档互
  链、README 双语索引与结构树行同步。
