## v0.99 — 工程化: 部署链路与分享元数据

**变更性质：工程化（部署脚本加固与站点元数据补全）**
**开发时间：2026-09-16**

### 概述

部署链路四项加固。显式传入的部署目标与站点地址此前会被
用户侧配置文件静默覆盖，改为显式值优先并在部署前打印最终
生效值；前置质量关卡由单测加计数守恒扩展为完整 check
（构建与类型检查、单测、计数守恒、lint 与格式），并新增
工作树未提交改动软校验；站点分享元数据补齐 og:url 与
canonical，og:image 等地址在部署时注入为线上绝对地址，
仓库与构建产物保持无域名相对形态；浏览器图标由框架默认
标志重绘为星核与戴森球轨道意象。行为数值零变化，存档零
迁移。

### 变更明细

- 部署脚本 deploy.sh：显式传入的 DEPLOY_DEST 与 DEPLOY_URL
  优先于 env 文件配置（修复 source 覆盖外部值），目标目录与
  站点地址在部署前打印最终生效值；前置关卡改跑完整 check，
  计数守恒的 Playwright 段经 STARCORE_PW_DIR 环境变量启用；
  工作树不干净时告警但不阻断
- 分享元数据：index.html 新增 og:url 标签并补 noscript 提示；
  deploy.sh 在产物同步后按站点地址注入 og:image 与 og:url
  绝对地址并随 og:url 行插入 canonical（仓库缺省，相对形态的
  link href 会被构建当资产处理而失败），注入命中异常时告警
- 图标：public/favicon.svg 由框架默认标志重绘为发光星核加
  双轨道环与卫星点（主色取设计令牌青色系 #00e5ff，深色圆角
  底），体积由 9522 字节减至 767 字节

### 验证

- 部署沙箱彩排：显式值优先与 env 文件兜底两条路径的目标
  目录均正确，分享元数据注入 og 命中 2/2、canonical 1/1，
  工作树软校验告警按预期出现
- corepack pnpm check 全绿（32 文件 491 用例）+ 含
  Playwright 目录的计数守恒全绿
- 全套件 27 脚本 preview 通过（发版脚本线上端版本断言按
  已知形态待部署后复跑），v084 分享卡断言随注入口径扩展

**变更性质：修复（气泡层级契约、视图杂项七项、数据清扫九项）**
**开发时间：2026-09-15**

### 概述

重复的枚举清单改派生；遗物套装文案弃用按全角冒号拆整段
label 的脆弱拼装，改专用短文案字段；稀有度取色函数与徽标
卡名样式三处拷贝收敛为单一出处；资源区与成本标签补读屏
名称文本。

## v0.96 — 修复: 焦点陷阱、卡片语义与样式卫生

**变更性质：修复（弹窗焦点陷阱、卡片交互语义、样式卫生）**
**开发时间：2026-09-15**

### 概述

弹窗焦点陷阱此前有三处缺陷。「常真激活加父级卸载」路径（强化
弹窗）关闭时只摘监听、不把焦点还给触发元素；在弹窗内点击非聚焦
区域后焦点落到页面背景，再按 Tab 会逃出弹窗；环绕序列混入禁用
与隐藏节点，首末判定可能失效。本次在卸载时仍激活的路径上补还焦，
Tab 处理开头补弹窗外焦点拉回，环绕序列过滤禁用与不可见节点，
并为焦点陷阱新增七条组件级用例，自该能力引入以来首次有回归保护。

编队卡的「选中」此前没有任何消费方：点击或键盘选中只改变高亮
样式，战斗编队选择在战斗页独立完成，属于伪交互。本次移除编队卡
的选中状态与交互语义，卡片转为纯内容容器。遗物图鉴卡与编队卡
此前以 role="button" 承载整体点击、内部又嵌套原生按钮，属嵌套
交互元素的误用；本次把卡片主操作平铺为显式按钮：图鉴卡新增
「装备」按钮（已装备时转为禁用态「已装备」），选材模式下改为
「选为材料 / 取消选材」；编队操作本就全由行内按钮承担，卡片
不再整体可点。

样式层做一轮卫生清理：reduced-motion 全局规则补动画次数限制，
无限循环动画不再以 0.01ms 周期空转闪烁；跃迁 overlay 的死规则
与从未生效的降级声明清出（实现本在 AppShell scoped，全局
!important 规则又压住了那份显式降级）；背景空壳规则、弹窗遮罩
浅色死样式、明细行永不命中的末行选择器一并删除；三处视图对全局
工具类的 scoped 重复与分叉收敛为全局修饰变体；补登按钮基础骨架
类（兜底屏出口此前使用未定义类）；主题色硬编码统一改 color-mix
走 token，样式表与组件层全量清理；移动端提示条抬高，避开战斗页
浮动返回条。

## v0.95 — 修复: 错误屏出口可靠性与运行期兜底

**变更性质：修复（错误屏出口、下载可靠性、运行期兜底、显示与导航交互）**
**开发时间：2026-09-15**

### 概述

错误屏的两个出口此前在失败路径上不可观测：导出损坏档时下载链接
未挂入文档，对象地址在点击后同步回收，部分浏览器可能在下载开始
前即失效，而损坏档是玩家的唯一副本；清除存档重开遇到异常时请求
裸抛，界面表现为「点了没反应」，没有任何反馈。本次改为链接入
文档后延迟回收对象地址，清除失败给出可见提示，并对进行中的清除
请求加防重入。

应用此前没有全局错误兜底，渲染、生命周期或事件处理中的未捕获
异常只打印到控制台，页面停在半渲染或空白状态，玩家没有出口。
本次注册全局错误处理器，把此类异常导向运行期兜底屏，提供刷新
页面、导出存档与清除存档重开三种出口，屏上标题与提示按存档
读取三态与运行期异常分别切换。

数值格式化此前对 number 与 Decimal 两种入参走两套路径：number
路径按引擎原生四舍五入，Decimal 路径按全局截断配置取数，同一
数值会因传参类型显示不同结果；负值在小数量级会越过单位边界，
如 -999.5 显示为 -1000 而 -1000 显示 -1K，形成断层；极小负值
显示 -0；超出最大后缀档的科学计数法残留尾零。本次把 fmt 收敛为
单一 Decimal 路径，负数侧改朝零截断并归一负零，科学计数法统一
去尾零，pct 同步归一负零。

成就页「已获得加成」此前把各成就的标注值直接相加，与实际生效的
连乘口径不一致，系统性低报各面加成；部队页「全军战力」与部队卡

系统实际生效值同源；全军战力与「已拥有」改用库存加编队的全量
口径，空状态判定同步。战斗页敌方部署的攻击、防御与血量及编队
战力此前裸数字输出，大数值下出现指数记号，统一接入 fmt 管线。

导航层此前有三处缺陷：桌面侧栏折叠后标签只做透明处理仍占布局，
把导航图标压缩至零宽，折叠态整列图标不可见；战斗页不属于任何
导航层级，上下导航却把当前位置回退标记为「主界面」并高亮，对
视觉与读屏都是错误导向；移动端「更多」面板打开后不能用 Escape

## v0.81 — 修复: 存档安全链：损坏档保护与校验收紧

**变更性质：修复（存档读写链路六项缺陷收口，其中一项可致数据丢失）**
**开发时间：2026-09-09**

### 概述

数值串校验曾接受任意位指数，注入超长指数可让无限大写进存档，下次读
档整档判废；损坏档与无档不可区分，读档失败后静默开新档，自动存档即
覆盖原始数据。本版双道收紧数值校验并为损坏档新增专门状态与错误屏，
提供导出原始存档出口；顺路收口同测试面的六项校验与编码卫生。存档结
构零变化，版本号不变，旧档无感兼容。

### 变更明细

- 数值串指数限位：
  - 科学计数法指数位数限 1 到 6 位，超长指数在校验层直接拒档
  - 负熵反序列化增加有限性兜底，非有限值钳 0，两道防线共同杜绝
    无限大经序列化写进存档
- 损坏档专门状态：
  - 读档结果新增损坏态，与无档严格区分；仅当双通道确实存在存
    储值但全部不可读时报损坏，主备双档取保存时间更新的一档
  - 损坏态进入错误屏，提供导出原始存档（原始载荷原样下载）与
    清除存档重开两个出口
  - 错误态下一切存档写入被拒绝，自动存档与关闭页面前的同步存
    档均不再覆盖原始数据
- 转生树幂聚合：
  - 无限节点效果不再按等级逐份展开物化数组，改为单条携带等级
    的聚合条目，乘数型按值取幂、加法型按值乘等级，语义等价
  - 配合无限节点等级硬上限（百万级，正常进度不可触顶），超限
    存档在校验层拒绝，超大等级值不再可能挂死首帧
- 导入替换语义：
  - 导入存档前先全量重置各 store 再写入，缺省字段回落初始值
  - 转生次数为 0 可正常清零，不再保留内存现值

  - 战斗页对越界编队选择回退首支，异常档不再触发页面崩溃
- 校验与编码卫生：
  - 训练任务数量必须为非负整数（小数曾可入档并在完成时产出小数
    兵力致整档判废），转生次数必须为非负整数
  - 导入编解码改用标准文本编码接口替换已废弃的转义函数，中文与
    表情符号导出导入往返无损，旧导出码互通
  - 多处注释与实现口径对齐
