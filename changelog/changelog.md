## v1.12 — 重构: 界面层文案抽离与多语言地基

**变更性质：重构（文案抽离为语言包，新增取词门面与语言识别，零行为变化）**

**开发时间：2026-09-20**

### 概述

为多语言扩展打地基：界面层全部中文文案从代码中抽离，集中到按域
拆分的语言包，代码统一经取词门面引用；同时落地默认语言识别（浏览
器语言匹配，无匹配回退简体中文）与显式选择持久化。当前仍只提供简
体中文，界面表现与既有文案逐字一致。

### 变更明细

- 取词门面：新增 `src/i18n/`，提供 `t(key, params)` 取词与命名插值、
  缺键回退默认语言；语言注册与默认语言识别在 `locale.ts`，规则为
  显式选择优先于浏览器匹配、再无匹配回退 zh-CN，选择持久化于
  `starcore_locale`。
- 语言包：新增 `src/locales/zh-CN/`，18 个域模块共 376 键，值逐字
  保真自抽取原文；界面层按域拆分为 common / nav / home / build /
  tech / map / army / battle / relics / prestige / achievements /
  save / offline / effects / app / game / resources / ui。
- 界面层迁移：47 个文件、439 处文案改走取词，其中 44 处动态消息转
  命名参数（如 `训练 {unitName} ×{count}`）；覆盖 33 个组件与视图、
  14 个脚本模块（含 store 消息、组合式函数与存档链路提示）。
- 守卫与工程化：新增 `scripts/check-locales.mjs` 缺键扫描，语言包键
  与调用键 376 对 376 双向一致；`tsconfig.app.json` 开放显式 .ts
  后缀导入，语言文件可被纯 Node 工具链直接加载；计数守恒脚本适配
  目录导入解析。
- 兼容性：运行时零行为变化；新增测试 2 个文件 24 个用例，测试基线
  由 33 文件 476 用例更新为 35 文件 500 用例。

### 验证

- corepack pnpm check 全绿：35 个测试文件 500 个用例。
- 含 Playwright 段与文案扫描的计数守恒全绿；抽取前后逐条比对零丢失。
- Playwright 回归套件 27 脚本全过。
